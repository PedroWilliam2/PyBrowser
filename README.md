# PyBrowser
A browser built in Python using tkinter, requests, and camoufox—it doesn't render JavaScript because that’s just too much of a mess to deal with. Anyway, "Grumete" (cabin boy/apprentice sailor)—from what I’ve learned, that’s what they used to call the assistants or young crew members who helped with navigation; and since this is a good browser, the name is self-explanatory.
